# BlindStudy

An interactive e-learning platform landing page built with React, Vite, Tailwind CSS, and Framer Motion. 

[Live Preview](https://66969124e850a1d38f4bbd94--mellifluous-sunburst-4a5303.netlify.app/)

---

## Features

- **Responsive Design**: Optimized for mobile, tablet, and desktop viewports.
- **Interactive UI**: Animated transitions and interactive components powered by Framer Motion.
- **Modern Components**: 
  - Responsive Navbar & Mobile Navigation
  - Hero Section
  - About Section
  - Featured Courses Listing
  - Meet the Instructors (Teachers) Section
  - FAQ Accordion
  - Contact Form
  - Detailed Footer

---

## Tech Stack

- **Framework**: React (with Vite)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: React Icons

## Getting Started

### Prerequisites

Make sure you have Node.js (version 22 or higher recommended) installed.

### Installation & Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/eNVy047/blindstudy.git
   cd blindstudy
   ```

2. **Install exact dependencies:**
   ```bash
   npm ci
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

### Running with Docker

You can also run the application using Docker:

1. **Build the image:**
   ```bash
   docker build -t blindstudy-app .
   ```

2. **Run the container:**
   ```bash
   docker run -p 5173:5173 blindstudy-app
   ```

Open `http://localhost:5173` in your browser.
